## 背景
需要解决什么问题，业务和技术约束是什么？

## 决策因素
兼容性、维护周期、安全、性能、可用性、运维成本、团队熟悉度、许可证/供应链风险、视觉一致性和可访问性（如适用）。

## 候选方案
至少列出两个合理选项、优缺点和成本。

## 决策
明确批准的技术、精确版本、架构边界或视觉行为，不使用“最新版”等模糊表述。

## 影响
新增依赖、接口/数据兼容性、迁移步骤、风险、团队影响。

## 验证
构建、测试、可访问性检查、性能检查或试点结果。

## 回滚/退出策略
说明失败时如何恢复。

## 审批与复审
批准人、批准日期、复审日期和触发条件。
